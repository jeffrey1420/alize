**Promise:** Useful AI agents that do real work — not demos, not chatbots, not promises. Time saved, fewer repetitive tasks, more speed, more control.

Alizé doesn't sell technology. The client buys: time saved, fewer repetitive tasks, more speed, more control, better use of their tools, serious and sustained implementation.

**What Alizé is not:** a prompt agency, a gadget chatbot vendor, a consulting firm that deploys nothing, a promise to replace teams, a self-service marketplace.

## Vision

AI in business is often poorly sold: too many buzzwords, too many demos, not enough framing. Alizé exists to transform AI into a usable operational tool — starting from real business needs, not technological fantasies.

The French SME/ETI market is underserved by AI agents: global platforms are generic, self-service tools require technical maturity that most businesses don't have, and "AI strategy consulting" produces decks, not working agents.

Alizé fills the gap: a managed, governed, professionally deployed agent service built for French companies that want real results, not another dashboard.

## Mission

Help French businesses identify, deploy, and manage AI agents capable of handling repetitive, standardizable, or time-consuming tasks in their business processes — with security, governance, and measurable outcomes.

### MCP Integration (Key Differentiator)

**What is MCP:** Model Context Protocol — Anthropic's open standard for connecting AI models to external tools and data sources. Think "USB for AI agents."

**Why MCP-first matters for Alizé:**
- Standardized tool abstraction: any MCP server can be an agent tool
- Skills portability: skills built on MCP work across frameworks
- Ecosystem leverage: 7,000+ MCP servers available (per awesome-mcp-servers lists)
- French compliance: MCP servers can be self-hosted on OVHcloud, keeping data in France
- Future-proof: MCP is becoming the industry standard (Anthropic, OpenAI, Google, Microsoft all supporting it)

**Alizé MCP Architecture:**
```
Agent (Mastra runtime)
├── Built-in tools (search, memory, scheduling)
├── MCP Client ──────────────► MCP Server (your tools)
│                               ├── Slack MCP
│                               ├── Notion MCP
│                               ├── Gmail MCP
│                               ├── CRM MCP (HubSpot, Pipedrive)
│                               └── Custom business tool MCP
└── RAG pipeline
    ├── Document ingestion (PDF, DOCX)
    ├── Chunking + embedding (Mistral or Cohere)
    ├── pgvector storage
    └── Retrieval + generation
```

**Alizé's MCP advantages:**
- Self-hosted MCP servers on French infrastructure for data sovereignty
- Custom MCP servers built per-client for their specific business tools
- Skills system built on agentskills.io open standard (SKILL.md format, progressive disclosure loading)

### Self-Improvement Architecture (4-Layer)

Inspired by NousResearch Hermes Agent. Learning at the knowledge level, not the weight level.

**Layer 1 — Runtime Learning (immediate, no GPU)**
- Bounded curated memory (MEMORY.md ~2KB, USER.md ~1KB)
- Frozen snapshot at session start (enables prefix caching)
- Agent-curated: character limits force prioritization
- Security scanning for prompt injection before acceptance

**Layer 2 — Skill System (procedural memory)**
- Autonomous skill creation after complex tasks (5+ tool calls)
- Format: SKILL.md following agentskills.io open standard
- Progressive disclosure: list → view → detailed reference
- Self-created after user corrections or discovered workflows

**Layer 3 — Session Search (episodic recall)**
- SQLite FTS5 full-text search over all past conversations
- On-demand LLM summarization of retrieved sessions
- Separate from bounded curated memory

**Layer 4 — Offline Evolution (periodic)**
- DSPy + GEPA (Genetic-Pareto Prompt Evolution) on execution traces
- ~$2-10 per optimization run, no GPU
- Human-gated: outputs PRs for review before deployment
- Phased rollout: skills → tool descriptions → system prompts

## Objections — Updated with Competitive Angles

### "Not reliable enough for our business"
**Old response:** We don't deploy without a framework, limited rights, controlled actions.
**Updated:** Alizé agents run within strict permission boundaries you define. They can't access data outside their scope, can't take actions without validation where you require it, and every action is logged. Our agents are bounded — they do exactly what they're designed to do, nothing more. This is fundamentally different from a generic AI assistant that can do anything.

### "Risky for our data"
**Old response:** Controlled infrastructure, access rules, logging, clear scope.
**Updated:** All data stays on French infrastructure (OVHcloud, EU data centers). We operate under EU AI Act requirements, not just US-based terms of service. Unlike global AI platforms where your data may train models, Alizé agents don't use your data for training. You own the data, we just process it. Plus: per-client database isolation, no data leakage between clients.

### "Our teams will reject the tool"
**Old response:** Adoption prepared, use cases that relieve burden, training.
**Updated:** This is where self-service tools like Agentova fail — they assume users will configure and adapt on their own. Alizé includes structured training and a 30-day monitoring period where we handle all adjustments. Your teams see results first, friction second. We also set realistic expectations upfront: our agents don't replace people, they remove the repetitive tasks people hate.

### "We don't know if ROI will be there"
**Old response:** Pilot on measurable friction.
**Updated:** We structure pilots around measurable outcomes: hours saved, tickets resolved, response time reduced. Before we deploy, we quantify the expected ROI. After 30 days, we show you the actual numbers. If the pilot doesn't deliver measurable value, we don't push for a contract. Agentova can't offer this — they sell you a tool and wish you luck.

### "We don't want to turn everything upside down"
**Old response:** Progressive, pragmatic, controlled approach.
**Updated:** We start with one workflow. One agent doing one job. When that works, we expand. You're never deploying a company-wide transformation — you're adding one AI employee at a time. And unlike a self-service tool where you're responsible for the setup, we're with you at every step.

### NEW: "Why not just use Agentova / ChatGPT / Claude?"
**Response:** Those tools work if you know what you're doing. Most businesses don't have someone who does. Agentova is a marketplace — you still choose, configure, and maintain the agents yourself. ChatGPT and Claude are powerful, but they're generic — they don't connect to your actual business tools unless you build the integrations yourself. Alizé does the integration work, manages the agent, and optimizes it over time. You buy a working AI employee, not a software license.

### NEW: "This seems expensive"
**Response:** Compare it to the alternative: a part-time administrative employee costs €1,500-2,500/month for 20 hours/week. An Alizé agent works 24/7 on the tasks you define, doesn't take sick days, doesn't need management, and costs €800-1,500/month. The ROI isn't theoretical — we measure it in the pilot.

### NEW: "Our industry has specific regulations (legal, healthcare, finance)"
**Response:** Alizé is built for regulated environments. EU AI Act compliance is native, not bolted on. We can configure agents that operate within specific regulatory constraints — document handling, data retention, access controls. For highly regulated industries, we offer enhanced governance tiers with audit trails and validation workflows.
