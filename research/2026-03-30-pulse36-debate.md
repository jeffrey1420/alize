### Topic 2: Can Louis Deliver an AI Agent Solo?

**Assumption challenged:** D170 ("Louis delivers Pilot 1 solo") and D113 ("Louis delivers pilot 1 manually").

**Verdict: D170 conditionally correct, D113 confirmed wrong.**

**Key findings:**

- Louis's documented skill: web development internship. AI agent delivery requires LLM orchestration, MCP integration, RAG pipelines, vector DB administration, error handling for non-deterministic systems — none of which are covered by web dev experience.
- "Manual delivery" fails because web agency clients will know within 24 hours if the agent is running or if Louis is doing the work manually. Clients expect an agent that runs, not a consultant performing their task.
- Minimum viable web agency agent: Slack-triggered ticket triage creating Notion tasks. This is narrow enough (single trigger, single API call, no RAG) to be buildable solo.
- €2,000 flat pilot doesn't cover Louis's learning curve: 5-8 days of technical ramp-up + 3-5 days of build = €1,600-2,600 in opportunity cost alone, before client delivery starts.

**Recommendation:** 3-day technical self-test before committing to solo delivery. First 1-2 pilots treated as learning investment, not priced service.

### Topic 3: Is "Web Agencies" the Right First Vertical?

**Assumption challenged:** D181 ("web agencies/digital product companies confirmed as first vertical") based on D135 ("go where Grinto relationships exist").

**Verdict: Wrong on three independent grounds.**

**Key findings:**

- **Conflict of interest:** Louis co-founded a web agency. If Alizé sells AI agents to web agencies, it competes with Louis's own clients and his own co-founded company. U95/U107/U173 flagged this as critical and unresolved for 14+ pulses.

- **Navigation paradox:** D135 ("go where Grinto relationships exist") means leveraging Louis's current employer's relationships for competitive gain. When Grinto finds out, the internship ends. Reputation damage in the Caen digital community could be permanent.
- **Pattern:** Vertical has changed 4 times (professional services → expert-comptables → web agencies). U52 (Louis's actual network map) has been listed as critical gate for 35+ pulses and never completed. Every vertical decision was made without the prerequisite data.
