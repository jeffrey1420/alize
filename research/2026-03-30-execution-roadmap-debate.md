### ACTION 5: Define the ONE Workflow for the First Pilot
**What:** Write down one sentence describing what the first pilot agent will do:

> *"The agent [verb] [object] for [company type]."*

**Examples of valid one-sentence scopes:**
- "The agent routes incoming support requests to the right team for a 50-person service company."
- "The agent drafts follow-up emails from meeting notes for a 30-person consulting firm."
- "The agent extracts invoice data into a spreadsheet for an accounting practice."

**Why one sentence:** D81 through D81REVISED have been debating workflow selection for 10+ pulses without a decision. The debate keeps expanding the scope ("admin workflows around client management and regulatory reporting" is not one sentence, it's a paragraph). A one-sentence scope can be validated or invalidated in one discovery call. A paragraph-scope requires a 2-week diagnostic before you know if you're solving the right problem.

**What this produces:** A scope that can be explained in a LinkedIn message. A scope that fits on a scope document. A scope that a delivery contractor can execute.

**Blocker:** "I need to validate this with domain experts first" — wrong. You validate by sending outreach. The domain expert is the person you're talking to.

**This is a Louis decision. It gates the scope document, which gates the delivery partner contract, which gates the pilot.**
